Sección Informativa Teórica

1. La etiqueta HTML <canvas> y el contexto 2D

La etiqueta <canvas> de HTML5 funciona como un lienzo o mapa de bits en blanco donde se pueden renderizar gráficos y animaciones mediante JavaScript.

A diferencia de los elementos HTML estándar, el lienzo no tiene capacidad de dibujo propia. Para interactuar con él, se debe acceder a su contexto de renderizado 2D (usando canvas.getContext('2d') en JavaScript puro), el cual proporciona métodos y funciones para dibujar formas geométricas (rectángulos, arcos, líneas), definir estilos de relleno y trazo, manipular imágenes y procesar transformaciones matriciales.

2. Fundamentos de la librería p5.js

p5.js es una biblioteca de JavaScript diseñada para la programación creativa. Simplifica el uso y la manipulación de <canvas> al abstraer la sintaxis compleja del API nativo en funciones intuitivas.

La arquitectura principal de una aplicación en p5.js se estructura en torno a dos funciones esenciales:

  • setup(): Se ejecuta exactamente una vez al iniciar la aplicación. Se utiliza para preparar el entorno, definir el tamaño del lienzo con createCanvas(ancho, alto) e inicializar variables.
  • draw(): Se ejecuta en un bucle continuo (aproximadamente a 60 cuadros por segundo). Dentro de esta función se colocan las instrucciones de renderizado, animaciones e interacciones en tiempo real.
